# Linguagem Ubíqua

| Termo | Significado |
|---|---|
| Carga Química | Registro que representa uma carga de produto químico durante seu fluxo operacional. |
| Produto Químico | Produto associado a uma carga, identificado por informações cadastrais e classificação de risco. |
| Produto Ativo | Produto Químico habilitado para ser associado a novas cargas. |
| Número ONU | Código utilizado para identificar internacionalmente produtos e substâncias perigosas. |
| Classe de Risco | Classificação que representa o risco associado ao produto químico. |
| Responsável Técnico | Profissional tecnicamente responsável pela carga. |
| Registro Profissional | Identificação profissional que comprova a habilitação do Responsável Técnico. |
| Documento da Carga | Documento legal, licença, laudo ou certificado associado à carga. |
| Documentação Obrigatória | Conjunto de documentos exigidos para que a carga avance no fluxo. |
| Documento Válido | Documento que atende às condições de validade definidas pelo domínio. |
| Inspeção | Avaliação física ou documental de determinada carga. |
| Parecer Técnico | Resultado registrado após uma inspeção. |
| Liberação | Autorização para circulação ou saída da carga. |
| Bloqueio | Restrição que impede movimentação ou liberação. |
| Cancelamento | Encerramento definitivo do ciclo de vida de uma carga. |
| Status da Carga | Estado atual da carga no ciclo operacional. |
| Histórico da Carga | Registro imutável de eventos e alterações da carga. |
| Área de Armazenamento | Local destinado ao armazenamento seguro de cargas. |
| Capacidade de Armazenamento | Limite suportado por determinada área. |
| Compatibilidade de Armazenamento | Regra que determina se uma carga pode ocupar determinada área. |
